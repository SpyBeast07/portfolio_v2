# SvelteKit

SvelteKit is a framework for rapidly developing robust, performant web applications using Svelte. It provides a complete solution for building modern web apps with features like server-side rendering (SSR), client-side rendering (CSR), prerendering, file-based routing, form handling, and seamless data loading. SvelteKit leverages Vite for fast development with Hot Module Replacement (HMR), and offers adapters for deploying to various platforms including Node.js servers, static hosting, Vercel, Netlify, and Cloudflare.

At its core, SvelteKit implements a filesystem-based router where routes are defined by directory structure in `src/routes`. It handles everything from basic page routing to complex data loading patterns, form submissions with progressive enhancement, and API endpoints. The framework follows modern best practices including build optimizations, offline support via service workers, and configurable rendering strategies per route.

## Creating a Project

Create a new SvelteKit application using the `sv` CLI tool.

```bash
# Create a new SvelteKit project
npx sv create my-app

# Navigate to project directory
cd my-app

# Install dependencies
npm install

# Start development server
npm run dev
# Server starts at http://localhost:5173
```

## Page Components (+page.svelte)

Pages are Svelte components that define a route. They receive data from load functions via the `data` prop.

```svelte
<!-- src/routes/+page.svelte -->
<h1>Hello and welcome to my site!</h1>
<a href="/about">About my site</a>

<!-- src/routes/blog/[slug]/+page.svelte -->
<script>
	/** @type {import('./$types').PageProps} */
	let { data } = $props();
</script>

<h1>{data.title}</h1>
<div>{@html data.content}</div>
```

## Load Functions (+page.js / +page.server.js)

Load functions fetch data before a page renders. Use `+page.js` for universal loads (runs on server and client) or `+page.server.js` for server-only loads.

```javascript
// src/routes/blog/[slug]/+page.js - Universal load function
import { error } from '@sveltejs/kit';

/** @type {import('./$types').PageLoad} */
export function load({ params }) {
	if (params.slug === 'hello-world') {
		return {
			title: 'Hello world!',
			content: 'Welcome to our blog. Lorem ipsum dolor sit amet...'
		};
	}
	error(404, 'Not found');
}

// src/routes/blog/[slug]/+page.server.js - Server-only load function
import * as db from '$lib/server/database';
import { error } from '@sveltejs/kit';

/** @type {import('./$types').PageServerLoad} */
export async function load({ params }) {
	const post = await db.getPost(params.slug);
	if (post) {
		return post;
	}
	error(404, 'Not found');
}
```

Layouts wrap pages and can load their own data. They apply to all child routes.

```svelte

	let { children } = $props();
</script>

	<a href="/">Home</a>
	<a href="/about">About</a>
	<a href="/settings">Settings</a>
</nav>

{@render children()}

	/** @type {import('./$types').LayoutProps} */
	let { data, children } = $props();

<div class="submenu">
	{#each data.sections as section}
		<a href="/settings/{section.slug}">{section.title}</a>
```

## API Routes (+server.js)

Create API endpoints that handle HTTP requests directly.

```javascript
// src/routes/api/random-number/+server.js
import { error, json } from '@sveltejs/kit';

/** @type {import('./$types').RequestHandler} */
export function GET({ url }) {
	const min = Number(url.searchParams.get('min') ?? '0');
	const max = Number(url.searchParams.get('max') ?? '1');
	const d = max - min;

	if (isNaN(d) || d < 0) {
		error(400, 'min and max must be numbers, and min must be less than max');
	}

	const random = min + Math.random() * d;
	return new Response(String(random));
}

// src/routes/api/add/+server.js - POST handler
import { json } from '@sveltejs/kit';

/** @type {import('./$types').RequestHandler} */
export async function POST({ request }) {
	const { a, b } = await request.json();
	return json(a + b);
}

// Fallback handler for unhandled methods
/** @type {import('./$types').RequestHandler} */
export async function fallback({ request }) {
	return new Response(`I caught your ${request.method} request!`);
}
```

## Form Actions (+page.server.js)

Handle form submissions with server-side actions that support progressive enhancement.

```javascript
// src/routes/login/+page.server.js
import { fail, redirect } from '@sveltejs/kit';
import * as db from '$lib/server/db';

/** @type {import('./$types').PageServerLoad} */
export async function load({ cookies }) {
	const user = await db.getUserFromSession(cookies.get('sessionid'));
	return { user };
}

/** @satisfies {import('./$types').Actions} */
export const actions = {
	login: async ({ cookies, request, url }) => {
		const data = await request.formData();
		const email = data.get('email');
		const password = data.get('password');

		if (!email) {
			return fail(400, { email, missing: true });
		}

		const user = await db.getUser(email);
		if (!user || user.password !== db.hash(password)) {
			return fail(400, { email, incorrect: true });
		}

		cookies.set('sessionid', await db.createSession(user), { path: '/' });

		if (url.searchParams.has('redirectTo')) {
			redirect(303, url.searchParams.get('redirectTo'));
		}

		return { success: true };
	},
	register: async (event) => {
		// Handle registration
	}
};
```

```svelte
<!-- src/routes/login/+page.svelte -->
<script>
	import { enhance } from '$app/forms';

	/** @type {import('./$types').PageProps} */
	let { data, form } = $props();
</script>

{#if form?.success}
	<p>Successfully logged in! Welcome back, {data.user.name}</p>
{/if}

<form method="POST" action="?/login" use:enhance>
	{#if form?.missing}<p class="error">The email field is required</p>{/if}
	{#if form?.incorrect}<p class="error">Invalid credentials!</p>{/if}

	<label>
		Email
		<input name="email" type="email" value={form?.email ?? ''}>
	</label>
	<label>
		Password
		<input name="password" type="password">
	</label>
	<button>Log in</button>
	<button formaction="?/register">Register</button>
</form>
```

## Server Hooks (src/hooks.server.js)

Intercept and modify requests/responses at the server level.

```javascript
// src/hooks.server.js
import * as db from '$lib/server/database';

/** @type {import('@sveltejs/kit').Handle} */
export async function handle({ event, resolve }) {
	// Add custom data to event.locals
	event.locals.user = await db.getUserFromSession(event.cookies.get('sessionid'));

	// Custom route handling
	if (event.url.pathname.startsWith('/custom')) {
		return new Response('custom response');
	}

	const response = await resolve(event, {
		transformPageChunk: ({ html }) => html.replace('old', 'new'),
		filterSerializedResponseHeaders: (name) => name.startsWith('x-'),
		preload: ({ type, path }) => type === 'js' || path.includes('/important/')
	});

	response.headers.set('x-custom-header', 'potato');
	return response;
}

/** @type {import('@sveltejs/kit').HandleFetch} */
export async function handleFetch({ request, fetch }) {
	// Modify fetch requests during SSR
	if (request.url.startsWith('https://api.yourapp.com/')) {
		request = new Request(
			request.url.replace('https://api.yourapp.com/', 'http://localhost:9999/'),
			request
		);
	}
	return fetch(request);
}

/** @type {import('@sveltejs/kit').HandleServerError} */
export async function handleError({ error, event, status, message }) {
	const errorId = crypto.randomUUID();
	console.error(error);
	return {
		message: 'Whoops!',
		errorId
	};
}
```

## Remote Functions (Experimental)

Type-safe server functions callable from anywhere in your app.

```javascript
// src/routes/blog/data.remote.js
import * as v from 'valibot';
import { error, redirect } from '@sveltejs/kit';
import { query, form, command, prerender } from '$app/server';
import * as db from '$lib/server/database';
import * as auth from '$lib/server/auth';

// Query - read data from server
export const getPosts = query(async () => {
	return await db.sql`SELECT title, slug FROM post ORDER BY published_at DESC`;
});

// Query with validation
export const getPost = query(v.string(), async (slug) => {
	const [post] = await db.sql`SELECT * FROM post WHERE slug = ${slug}`;
	if (!post) error(404, 'Not found');
	return post;
});

// Batched queries - solve n+1 problem
export const getWeather = query.batch(v.string(), async (cities) => {
	const weather = await db.sql`SELECT * FROM weather WHERE city = ANY(${cities})`;
	const lookup = new Map(weather.map(w => [w.city, w]));
	return (city) => lookup.get(city);
});

// Form - write data with form submissions
export const createPost = form(
	v.object({
		title: v.pipe(v.string(), v.nonEmpty()),
		content: v.pipe(v.string(), v.nonEmpty())
	}),
	async ({ title, content }) => {
		const user = await auth.getUser();
		if (!user) error(401, 'Unauthorized');

		const slug = title.toLowerCase().replace(/ /g, '-');
		await db.sql`INSERT INTO post (slug, title, content) VALUES (${slug}, ${title}, ${content})`;
		redirect(303, `/blog/${slug}`);
	}
);

// Command - mutations without forms
export const addLike = command(v.string(), async (id) => {
	await db.sql`UPDATE item SET likes = likes + 1 WHERE id = ${id}`;
});

// Prerender - static data at build time
export const getStaticPosts = prerender(async () => {
	return await db.sql`SELECT title, slug FROM post`;
});
```

```svelte
<!-- src/routes/blog/+page.svelte -->
<script>
	import { getPosts, createPost } from './data.remote';
</script>

<h1>Recent posts</h1>
<ul>
	{#each await getPosts() as { title, slug }}
		<li><a href="/blog/{slug}">{title}</a></li>
	{/each}
</ul>

<h2>Create new post</h2>
<form {...createPost}>
	<label>
		Title
		<input {...createPost.fields.title.as('text')} />
	</label>
	<label>
		Content
		<textarea {...createPost.fields.content.as('text')}></textarea>
	</label>
	<button>Publish!</button>
</form>
```

```javascript
// Using error helper in load functions
import { error } from '@sveltejs/kit';

/** @type {import('./$types').PageServerLoad} */
export function load({ locals }) {
	if (!locals.user) {
		error(401, 'not logged in');
	}
	if (!locals.user.isAdmin) {
		error(403, 'not an admin');
	}
}

// Redirects
import { redirect } from '@sveltejs/kit';

/** @type {import('./$types').PageServerLoad} */

	if (!locals.user) {
		redirect(307, '/login');
	}
```

## Navigation ($app/navigation)

Programmatic navigation and cache invalidation.

```svelte
<script>
	import { goto, invalidate, invalidateAll, afterNavigate, beforeNavigate } from '$app/navigation';

	async function handleClick() {
		// Navigate programmatically
		await goto('/dashboard');

		// Navigate with options
		await goto('/search?q=test', { replaceState: true });
	}

	async function refreshData() {
		// Invalidate specific URL
		await invalidate('https://api.example.com/data');

		// Invalidate custom dependency
		await invalidate('app:random');

		// Invalidate all load functions
		await invalidateAll();
	}

	beforeNavigate(({ from, to, cancel }) => {
		if (hasUnsavedChanges) {
			if (!confirm('You have unsaved changes. Leave anyway?')) {
				cancel();
			}
		}
	});

	afterNavigate(({ from, to }) => {
		console.log(`Navigated from ${from?.url} to ${to?.url}`);
	});
</script>

<button onclick={handleClick}>Go to Dashboard</button>
<button onclick={refreshData}>Refresh Data</button>
```

## Adapter Configuration (Node.js)

Deploy to a Node.js server.

```javascript
// svelte.config.js
import adapter from '@sveltejs/adapter-node';

/** @type {import('@sveltejs/kit').Config} */
const config = {
	kit: {
		adapter: adapter({
			out: 'build',
			precompress: true,
			envPrefix: ''
		})
	}
};

export default config;
```

```bash
# Build and run
npm run build
node build

# With environment variables
HOST=127.0.0.1 PORT=4000 ORIGIN=https://my.site node build

# With .env file (Node 20.6+)
node --env-file=.env build
```

```javascript
// Custom server with Express
import { handler } from './build/handler.js';
import express from 'express';

const app = express();

app.get('/healthcheck', (req, res) => {
	res.end('ok');
});

app.use(handler);

app.listen(3000, () => {
	console.log('listening on port 3000');
});
```

## Cookies and Session Management

Manage cookies in server-side code.

```javascript
// src/routes/+layout.server.js
import * as db from '$lib/server/database';

/** @type {import('./$types').LayoutServerLoad} */
export async function load({ cookies }) {
	const sessionid = cookies.get('sessionid');
	return {
		user: await db.getUser(sessionid)
	};
}

// src/routes/login/+page.server.js
/** @satisfies {import('./$types').Actions} */
export const actions = {
	login: async ({ cookies, request }) => {
		const data = await request.formData();
		// ... validate user

		cookies.set('sessionid', await db.createSession(user), {
			path: '/',
			httpOnly: true,
			sameSite: 'strict',
			secure: process.env.NODE_ENV === 'production',
			maxAge: 60 * 60 * 24 * 7 // 1 week
		});
	},
	logout: async ({ cookies }) => {
		cookies.delete('sessionid', { path: '/' });
	}
};
```

## Universal Hooks (src/hooks.js)

Hooks that run on both server and client.

```javascript
// src/hooks.js
import { Vector } from '$lib/math';

/** @type {import('@sveltejs/kit').Reroute} */
export function reroute({ url }) {
	const translated = {
		'/en/about': '/en/about',
		'/de/ueber-uns': '/de/about',
		'/fr/a-propos': '/fr/about'
	};
	if (url.pathname in translated) {
		return translated[url.pathname];
	}
}

// Transport hook for custom types across server/client boundary
/** @type {import('@sveltejs/kit').Transport} */
export const transport = {
	Vector: {
		encode: (value) => value instanceof Vector && [value.x, value.y],
		decode: ([x, y]) => new Vector(x, y)
	}
};
```

## Environment Variables

Access environment variables safely in server and client code.

```javascript
// Server-only (private) environment variables
// src/routes/+page.server.js
import { API_KEY, DATABASE_URL } from '$env/static/private';
import { env } from '$env/dynamic/private';

export function load() {
	// Static imports - replaced at build time
	console.log(API_KEY);

	// Dynamic access - read at runtime
	console.log(env.API_KEY);
}

// Client-safe (public) environment variables
// Must be prefixed with PUBLIC_
// src/routes/+page.svelte
<script>
	import { PUBLIC_API_URL } from '$env/static/public';
	import { env } from '$env/dynamic/public';
</script>

<p>API URL: {PUBLIC_API_URL}</p>
<p>Dynamic: {env.PUBLIC_FEATURE_FLAG}</p>
```

SvelteKit excels at building full-stack web applications that require both excellent developer experience and production-grade features. Common use cases include marketing sites with dynamic content, e-commerce platforms, dashboards and admin panels, blogs and content sites, and API backends. The framework's flexibility allows progressive enhancement from static sites to fully dynamic applications.

Integration patterns typically involve combining SvelteKit's file-based routing with external services like databases (via server-only modules), authentication providers (via hooks and cookies), and APIs (via load functions and remote functions). The adapter system enables deployment to virtually any hosting platform while maintaining consistent application behavior across environments.
